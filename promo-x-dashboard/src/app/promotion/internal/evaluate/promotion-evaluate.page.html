Calling it from your checkout

Your checkout sends the cart to promo-x-core and shows the customer the prices it gets back. The example below is the cart above, so changing the form changes it.

Use a dedicated integration client

Create a user or client for your checkout in the identity provider (Keycloak) with only the integration-client role, and call the API with its token. Don't reuse a staff account: integration-client can evaluate carts and confirm or cancel usages, and nothing else.

Request

POST {{ apiUrl }}/api/promotion/evaluate

Authorization
Bearer <token>, the integration client's access token
X-Storefront-Id
{{ storefrontId() }}, this storefront
Content-Type
application/json

Example

{{ curl() }}
Field Type Meaning
promoCodes string[], required The codes the customer entered. [] for none.
items object[], 1–{{ maxItems }} The cart's lines.
items[].productExternalId string, required Your ID of the product. It must exist in this storefront's catalog: its SKU and categories are taken from there.
items[].quantity integer, ≥ 1 How many units.
items[].unitPrice decimal, ≥ 0 The price of one unit before promotions, in the storefront's currency.
shippingCost decimal, ≥ 0 The order's shipping cost before promotions.
customerId string, optional Your customer ID. Leave it out for an anonymous guest.
sessionId string, optional Your cart or session ID, stored with the usage.
reserveUsage boolean, default true See below.

Response

newTotal is what the customer pays, and totalDiscount what they save. Each of items has its discountAmount and priceAfterDiscount; shipping has newShippingCost. appliedRules lists the rules that changed the cart, and matchedRules those whose conditions matched, even if they changed nothing. Open "Request and response" on a result above to see a full one.

Usage limits and reserveUsage

This page sends reserveUsage: false, so the uses of usage-limited rules count right away. That suits a checkout that prices the cart once, when the order is placed. A checkout that prices it earlier can send true (the default) instead: the uses are then held, and it calls POST /api/promotion/usage/{usage.id}/confirm when the order is placed, or …/cancel when it's abandoned. A held use that isn't confirmed is given back after 15 minutes.

Errors

  • 400: the cart is malformed, such as a missing field or a negative price. errors[].path names the field.
  • 409 PRODUCT_EXTERNAL_IDS_NOT_FOUND: a product isn't in the storefront's catalog; errorContext.missingProductExternalIds lists them.
  • 401: no token, or it expired. 403: the token lacks the integration-client role.
